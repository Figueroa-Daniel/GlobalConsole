# Tecnologías

Este archivo documenta las tecnologías y librerías utilizadas en el proyecto.

## 1. Lenguaje de Programación

- **Kotlin:** 2.4.0

## 2. Framework de UI

- **Compose Multiplatform:** 1.11.1

## 3. Arquitectura

- **AndroidX Lifecycle:** 2.11.0-beta01 (ViewModel y Lifecycle para MVVM)
- **Inyección de Dependencias (Propuesta):**
    - **Koin:** Se propone Koin para la inyección de dependencias por su simplicidad y buen soporte para Kotlin Multiplatform. No se ha podido añadir la dependencia al proyecto por no encontrar las coordenadas correctas.
## 4. Asincronía

- **Kotlinx Coroutines:** 1.11.0

## 5. Componentes de UI

- **Material 3:** 1.11.0-alpha07

## 6. Pruebas

- **JUnit:** 4.13.2

## 7. Soporte de Hardware

- **Gamepad (Propuesta):**
    - **Jamepad:** Se propone Jamepad para la gestión de la entrada de gamepad. No se ha podido añadir la dependencia al proyecto por no encontrar las coordenadas correctas.
